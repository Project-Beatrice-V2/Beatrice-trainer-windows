Workflow

  1. Export your dataset as a ZIP with the button on the right, or use a Hugging Face dataset ID in the notebook.
  2. Open the notebook in Colab or Kaggle and switch the runtime to a GPU.
  3. Run the cells in order: install, dataset, settings, then training.
  4. Run Download Output and choose VST3 Paraphernalia to get beatrice_vst3_files.zip.
  5. Import the ZIP in the Beatrice voice changer with Upload Custom Model.

Package your dataset

Zips every speaker's WAV files into beatrice_dataset.zip, ready to upload to the notebook.
